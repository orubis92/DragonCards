# Illustrazioni dei draghi

Ogni carta cerca automaticamente un'immagine `public/draghi/<id>.jpg` (per esempio `f01.jpg`
per il Cucciolo di Brace). Se il file non c'è, la carta usa l'icona vettoriale integrata:
il gioco è completo anche senza immagini. Formato consigliato: JPG, circa 400×300 px,
orientamento orizzontale (l'immagine viene ritagliata al centro con `object-fit: cover`).
